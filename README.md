В Git необходимо создавать ветки для изоляции изменений, чтобы не нарушить стабильность основного кода. Основными являются main/master (продакшн) и develop (разработка). Вспомогательные ветки — feature/ (новый функционал), release/ (подготовка релиза) и hotfix/ (срочные исправления). Никогда не ведите разработку напрямую в main
